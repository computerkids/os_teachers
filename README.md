# os_teachers

**信息技术教师参与开源项目**

只有通过学习并体验这个历程，教师才有可能在某一天与他的学生分享它。

## 愿景

鼓励信息技术教师亲身参与开源项目——读代码、提 issue、提交 PR、做文档——
把"参与开源"本身变成一次教学实践，让学生看到的不是课本里的概念，
而是真实世界的协作方式。

## 参与方式

1. **先体验**：在自己的 GitHub 账号上 fork 本仓库，按下面的练习完成一次真实的 PR。
2. **记下来**：把参与过程中遇到的困难、学到的技巧写成小文档，放在 `docs/` 目录。
3. **带回课堂**：把这段经历设计成一节课、一次社团活动或一个作业题目。

第一次参与开源不知道做什么？可以从这几件事开始：

- 给 README 纠错或润色文字（就是你现在在做的这件事）
- 翻译一段英文文档
- 给喜欢的项目提一个复现清晰的 issue
- 修一个拼写错误、补一条注释——小贡献也是贡献

## 如何把名字加进来（练习）

1. Fork 本仓库
2. 在 README 的"参与者"列表末尾加上你的 GitHub 用户名
3. 提交 PR，标题写 `添加<你的用户名>`
